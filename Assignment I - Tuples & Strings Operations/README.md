# Assignment I - Tuples & Strings Operations

## Overview
This assignment covers fundamental Python concepts including strings and tuples operations.

## Topics Covered
- **String Concatenation**: Combining multiple strings together
- **String Slicing and Indexing**: Accessing specific characters and substrings
- **String Methods**: Using built-in string methods like upper(), lower(), replace(), etc.
- **Tuple Creation**: Creating and initializing tuples
- **Tuple Access**: Accessing tuple elements by index
- **Tuple Operations**: Concatenation and repetition of tuples

## Files
- `Python_Assignment_1_Tuples_&_String_operations_.ipynb` - Jupyter Notebook with all code and exercises

## How to Use
1. Open the Jupyter notebook in Google Colab or your local environment
2. Follow the code cells sequentially
3. Run each cell to see the output
4. Modify and experiment with the code to understand better

## Key Concepts
- Strings are immutable sequences of characters
- Tuples are immutable sequences that can contain different data types
- Both support indexing and slicing operations
- String methods provide powerful text manipulation capabilities
