# 🐍 Python Fundamentals

A collection of Python assignments and projects created while learning Python fundamentals. This repository demonstrates core programming concepts through hands-on exercises and a mini real-world project.

**Topics Covered**

* Tuple operations
* String methods
* Text manipulation
* String indexing and slicing

### 📁 Assignment II – Data Structures & Conditional Statements

Explore Python's built-in data structures and decision-making concepts.

**Topics Covered**

* Lists
* Dictionaries
* Sets
* `if`, `elif`, and `else` statements

---

### 📁 Assignment III – Loops & Functions

Understand how to automate repetitive tasks and write reusable code.

**Topics Covered**

* `for` loops
* `while` loops
* User-defined functions
* Function parameters and return values
